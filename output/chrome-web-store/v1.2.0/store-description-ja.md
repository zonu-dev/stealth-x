# Chrome Web Store Description - Japanese

STEALTH X は、X (旧 Twitter) で画面共有・録画・スクリーンショットをするときに、自分のアカウント情報や自分のポスト内容をワンクリックで隠すための Chrome 拡張機能です。

データの外部送信は一切ありません。すべての処理はお使いのブラウザ内で完結します。

■ こんなときに使えます

- 配信・録画・画面共有で、自分の X アカウントを特定されたくないとき
- プレゼン資料やスクリーンショットに X を映す必要があるが、個人情報やポスト内容は隠したいとき
- 職場や公共の場で X を開くとき、肩越しに見られても素性が分かりにくくしたいとき

■ 隠せる項目

- 表示名（プロフィール上の名前）
- @ユーザー名（handle）
- プロフィールアイコン
- プロフィールのヘッダ画像
- プロフィール bio（自己紹介）
- 認証マーク
- ウェブサイト
- 位置情報（国 / 都市）
- 登録日（X の利用開始年月）
- 投稿数（「X 件のポスト」表示）
- 自分のポスト内容（本文・メディア・日時・反応数など）
- フォロー / フォロワー数

項目ごとにオン / オフを切り替えられます。マスタースイッチでまとめてオン / オフも可能です。

ポスト非表示をオンにすると、自分のポストは「クリックで表示」バッジ付きのマスク表示になります。クリックしている間だけ内容を一時的に確認できます。

■ 特徴

- 拡張機能アイコンをクリックするだけで即時に切り替え可能
- 設定は Chrome Storage に保存（Chrome 同期を使えば他端末にも自動反映）
- マスク対象は自分のアカウント情報と自分のポスト表示のみ
- 他人のアカウントや他人のポスト表示にはマスクをかけません
- X 上の投稿データやログイン状態は変更しません
- オープンソース（MIT ライセンス）

■ プライバシー

本拡張機能は、利用状況・アクセス履歴・アカウント情報・ポスト内容など、いかなるデータも収集・送信しません。処理はすべてあなたのブラウザ内で完結します。

■ 注意事項

- 本拡張機能はローカル表示の隠蔽を目的にしています。画面共有やスクリーンショット対策を 100% 保証するものではありません
- X の UI 変更により、一部のマスク対象が一時的に効かなくなる可能性があります。その際は GitHub Issues からお知らせください
- 自分のポスト内容は画面上で一時的に隠すだけで、X 上の投稿内容そのものは変更しません
- 認証情報、Cookie、アクセストークンは読み取りません
